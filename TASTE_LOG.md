# Taste log: what Anthony approved and rejected

The maker and the creative director both read this before every pin. Newest first. Quote him exactly. Each entry names
the pin file in pins/ so the reviewer can look at it.

## Rejected

- **pins/2026-11-19-coffee-still-up-v2.jpg** (Nov 18): "Having a faded out image like this in the corner is not in the
  design taste skill. It's poorly executed. The graph is fine but it looks gross." The problem was the tall photo crop
  parked in the bottom-right corner with feathered edges, floating in the field. The creative director passed it, which
  is why the hard-fail checks exist.
- **pins/2026-11-19-night-bloom-clock.jpg** (Nov 18): "The garden one looked bad, too, so I deleted it." A photo band
  feathered into the field on both edges, tiny chart labels, and too close to the coffee pin.
- **pins/2026-11-19-how-to-read-a-moth.jpg + pins/2026-11-19-what-the-howl-means.jpg** (Nov 18): two pins in a row with
  one skeleton (photo top, "FIELD NOTES / X" label, serif headline, rows of text, logo bottom left). "Fix the layout
  rule."
- **A fixed template renderer** (Nov 18): "Ew. I don't want the same layout every time."
- **The first rows-of-text "infographic"** (Nov 18): he asked for an infographic and got a one-fact pin. An infographic
  carries its information in a drawn visual (chart, scale, timeline, diagram), not in rows of text.

## Approved

- **pins/2026-11-19-carpool-setlist.jpg**: "Leave the carpool pin. That's great." He published it himself.
- **pins/2026-11-19-coffee-still-up-v3.jpg**: the redo with the photo full-bleed across the top and a hard edge.
  (Made by the coordinator; treat it as the reference for a chart pin, not yet a direct quote of approval.)

## Standing preferences (his words)

- "I need variety. Lists like tonite, infographics, illustrations, etc."
- "make sure that the color palette is always inspired by the image so it vibes well."
- "it's ok to have the color field fade out at the edge so it blends into the photo better. You don't have to be so
  blocky." Then: "That doesn't always have to be the default. If it looks good, use it." Then the coffee v2 rejection.
  Net rule: fades only as PIPELINE.md's Photo rules allow.
